# XGLCD Font API Reference

Complete reference for `xglcd_font.py`, a MicroPython/CircuitPython utility that
loads and renders proportional fonts in **X-GLCD 'C' format** — the `.c` font
files generated by the free MikroElektronika GLCD Font Creator (see
`www.mikroe.com/glcd-font-creator`).

Font files are plain text: one or more lines of comma-separated hex bytes (each
line starting with `0x`). Each letter is stored as a block of bytes whose first
byte holds that letter's pixel width.

This is the original font engine that ships with rdagger's `micropython-ili9341`
driver. `gfx_font.py` (`GfxFont`) is an alternative for Adafruit GFX `.h` fonts.

---

## Class `XglcdFont`

### `__init__(path, width, height, start_letter=32, letter_count=96)`

Load an X-GLCD font file.

| Arg | Type | Default | Description |
|-----|------|---------|-------------|
| `path` | str | — | Full path of the font file (e.g. `'fonts/ArcadePix9x11.c'`) |
| `width` | int | — | Maximum pixel width of each letter |
| `height` | int | — | Pixel height of each letter (clamped to a minimum of 8) |
| `start_letter` | int | `32` | ASCII code of the first letter |
| `letter_count` | int | `96` | Total number of letters in the font |

The loader only keeps lines that begin with `0x`, strips comments (`//`) and
trailing commas, and packs the bytes into the `letters` buffer.

```python
from xglcd_font import XglcdFont

font = XglcdFont('fonts/ArcadePix9x11.c', 9, 11)
neato = XglcdFont('fonts/Neato5x7.c', 5, 7, letter_count=223)
```

---

### Attributes

| Attribute | Type | Description |
|-----------|------|-------------|
| `width` | int | Maximum pixel width of each letter |
| `height` | int | Pixel height of each letter |
| `start_letter` | int | ASCII code of the first letter |
| `letter_count` | int | Total number of letters in the font |
| `bytes_per_letter` | int | Size of one letter's data block in bytes (`(floor((height-1)/8)+1) × width + 1`) |
| `letters` | bytearray | All letter byte data, concatenated |

The first byte of each letter's block is that letter's actual pixel width, so
the font is proportional even though `width` is the maximum.

`BIT_POS` is a class-level dict used internally by `lit_bits()` to translate
bitwise values into byte positions.

### `get_letter(letter, color, background=0, landscape=False)`

Convert a single letter's byte data into RGB565 pixel data.

| Arg | Type | Default | Description |
|-----|------|---------|-------------|
| `letter` | str | — | Character to render (must exist within the font) |
| `color` | int | — | RGB565 text color |
| `background` | int | `0` | RGB565 background color (0 = transparent) |
| `landscape` | bool | `False` | `True` = rotate the letter 90° (vertical text) |

The returned buffer is exactly the letter's own bitmap box: width comes from
the letter's stored width byte, height from the font height. This differs from
`GfxFont`, which returns the full advance box.

If the letter is outside the font (`ord(letter) - start_letter >=
letter_count`), a `Font does not contain character: ...` message is printed and
`(b"", 0, 0)` is returned.

**Returns:** `(buf, w, h)` — `buf` is a `bytearray` of RGB565 pixel data, `w`/`h`
are the letter's pixel width and height.

```python
buf, w, h = font.get_letter("A", color565(255, 255, 255))
```

> **Note:** `Display.draw_text()` calls `get_letter(letter, color, background)`
> without `landscape`, so letters are drawn in portrait orientation there.

---

### `measure_text(text, spacing=1)`

Measure the length of a text string in pixels.

| Arg | Type | Default | Description |
|-----|------|---------|-------------|
| `text` | str | — | Text string to measure |
| `spacing` | int | `1` | Pixel spacing added after each letter |

**Returns:** `int` — total pixel width (`sum` of each letter's stored width plus
`spacing`).

```python
text_w = font.measure_text("Hello")          # no extra spacing
x = (320 - text_w) // 2                      # center horizontally
```

## Quick start (MicroPython)

```python
from machine import Pin, SPI
from ili9341 import Display, color565
from xglcd_font import XglcdFont

spi = SPI(1, baudrate=40_000_000, sck=Pin(14), mosi=Pin(13))
display = Display(spi, dc=Pin(4), cs=Pin(15), rst=Pin(27), width=320, height=240)

font = XglcdFont('fonts/ArcadePix9x11.c', 9, 11)

text = "Hello!"
text_w = font.measure_text(text)
x = (320 - text_w) // 2
y = 120

display.draw_text(x, y, text, font, color565(255, 255, 255),
                  color565(0, 0, 255), spacing=1)
```

> **Tip:** The `fonts_glcd/` folder contains ready-made X-GLCD fonts
> (`ArcadePix9x11.c`, `Bally5x8.c`, `Neato5x7.c`, `Robotron13x21.c`, etc.).
> Pass each font's nominal `width`/`height` from its filename to the
> constructor, and use `letter_count=223` for fonts that extend past ASCII 127.
